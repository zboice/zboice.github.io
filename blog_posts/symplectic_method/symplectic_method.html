A bit about symplectic methods

By Zachary Boice

Introduction

Numerical Analysis shows us that we can create arbitrarily accurate numerical integration methods that are highly efficient and can cater to many different needs. However, many problems have an underlying physical character that we may be able to exploit to improve the accuracy of our numerical methods. Generally, we wish to examine systems that can be described by a Hamiltonian and exploit this property to better encapsulate the physics.

Motivation

Suppose we have a Hamiltonian system described by a phase space (with $q$ and $p$ as the canonical coordinates). We define a Poisson bracket on this phase space such that \[ \{u, v\} = \frac{\partial u}{\partial q}\frac{\partial v}{\partial p} - \frac{\partial u}{\partial p}\frac{\partial v}{\partial q} \] for two functions of phase space $u$ and $v$. Now, we define $\vec{X} = (q, p)^T$ to be the state vector at a given time. If we consider the Poisson bracket of $\vec{X}$ with itself, we find (in one dimension) that \[ \{\vec{X}, \vec{X} \} = \begin{pmatrix} 0 & 1 \\ -1 & 0 \end{pmatrix} \, , \] which we shall call $\Omega$.

We now consider a different set of canonical coordinates describing the same phase space: $(Q, P) = (Q(q,p), P(q,p))$, described by a state vector $\vec{\xi}$. These coordinates explicitly have a Poisson bracket \[ \{\vec{\xi}, \vec{\xi} \} = \frac{\partial \vec{\xi}}{\partial q}\frac{\partial \vec{\xi}}{\partial p} - \frac{\partial \vec{\xi}}{\partial p}\frac{\partial \vec{\xi}}{\partial q} = \mathcal{J}^T \Omega \mathcal{J} \] where $\mathcal{J}_{ij} = \frac{\partial \xi_i}{\partial X_j}$ is the Jacobian matrix of the coordinate transformation. But any canonical transformation must preserve Poisson brackets, and the Kronecker delta condition for positions and momenta must be the same in our new coordinates: $\{\vec{\xi}, \vec{\xi} \} = \Omega$. With these two relations, we find that \[ \mathcal{J}^T \Omega \mathcal{J} \equiv \Omega \] holds for canonical transformations (see [1] for a more robust and rigorous derivation).

The condition we derived above defines $\mathcal{J}$ to be a symplectic matrix (see [2] for more). Further, the determinant of $\mathcal{J}$ is the Poisson bracket of $(p,q)$ in the $(P,Q)$ coordinate system, so there is a fundamental link between Poisson brackets and Symplecticity. This relation has to do with the so-called "symplectic two-form", an important ingredient of the differential geometry underlying Hamiltonian mechanics. For now, it suffices to think about whether there might be a way for our computational framework to maintain the symplectic structure of our system, and use that to create a highly accurate numerical integrator.

Following Kessels in [3], we develop a numerical quadrature scheme that preserves the symplectic structure of the underlying space. We simply port Kessels' matlab code to python and discuss the implications of the numerical integration. More information on developing symplectic methods will come in a later blog post.

Problem statement

We shall examine the specific problem of (classical) motion around a star, using the Hamiltonian framework. Namely, the Hamiltonian takes the adimensional form \[ H = \frac{p_x^2 + p_y^2 + p_z^2}{2} - \frac{1}{\sqrt{q_x^2 + q_y^2 + q_z^2}} \] so that Hamilton's equations become \begin{align*} \dot{q}_i &= p_i \\ \dot{p}_i &= \frac{-q_i}{(q_x^2 + q_y^2 + q_z^2)^{3/2}} . \end{align*} This simple (and importantly separable) Hamiltonian of a non-chaotic system will provide a lot of information about why symplectic integration is usefull, and it illustrates a key reason for using a symplectic method.

This still isn't a perfect comparison. The scipy code is highly optimized whereas I wrote my code in about 20 minutes, with no real optimizations. Even with some optimization it's unlikely that the symplectic integrator will achieve the 100x speed up needed to beat LSODA. In the real world, people use symplectic integrators for many body gravitational systems or for situations where a small drift of function values could have catastrophic effects. So, it's definitely still worth understanding symplectic integrators, but part of that understanding is knowing when not to use one.
